# Banking_domain.sql
# 💳 Banking Domain SQL Project

A complete MySQL project that simulates a real banking system with:
- Customers
- Accounts
- Loans
- Credit Cards
- Transactions

This database is designed for SQL learning, data analysis practice, and portfolio building.

---

## 📂 Files
- **Banking_domain.sql** – Full database (schema + sample data + queries)
- **README.md** – Project documentation

---

## 🛠 Features
- Well-structured relational schema  
- 25+ customer records  
- 20+ accounts, loans, cards & transactions  
- Realistic banking data  
- Analysis queries included (fraud detection, customer insights, spending patterns)

---

## 🚀 How to Run
1. Open MySQL Workbench  
2. Go to **File → Run SQL Script**  
3. Select `Banking_domain.sql`  
4. Run and start querying
